# Разнообразие Забегов: Правило Поколения, Курс, набираемые Испытания и Престиж с Финала

Статус: принято (реализуется в слоях 3–5 плана `docs/plans/deepening.md`).

Все Поколения играются одинаково — растут только числа (масштаб ×1000, ADR-0001), — а после Финала контента играть незачем. Разнообразие дают три механизма, у каждого своя роль:

- **Правило Поколения** — один поворот правил на Поколение, заданный вручную, без случайности (например, «Ценовая война»: цены падают со временем Забега). Даёт каждому Поколению своё лицо.
- **Курс** — выбор на весь Забег при Престиже, 1 из 3 случайно предложенных из пула; сменить до следующего Престижа нельзя. Пройденные Правила Поколений пополняют пул Курсов, так что контент работает дважды. Случайность только в предложениях, выбранный Курс действует предсказуемо.
- **Испытания Забега**, которые можно брать несколько сразу. Их сумма — Класс риска — умножает Compute за этот Престиж, с потолком; пороги Класса открывают теневые Достижения. Образец — договор наказаний (Pact of Punishment) из Hades; слово «жар» занято Температурой, а «уровень» — запрещённый синоним Ранга, поэтому название «Класс риска» взято по образцу AI Safety Levels.

Престиж с Финала контента ведёт в любое уже пройденное Поколение по выбору игрока: высокий Класс риска на другом Правиле Поколения — это эндгейм без новых Моделей.

Каждое Правило и каждый Курс обязаны держать монотонность цены и Дохода по Рангу и полосу окупаемости 3× (`AGENTS.md`, правило 3). Проверка — тест с включённым вариантом, а не довод.

## Considered Options

- **Директивы** (слоты внутри Забега, 1 из 3 со слиянием, как в Balatro) — отложено. Это второй источник сборки в одном Забеге: читаемость Курса страдает, а сама сущность близка к отклонённой в ADR-0004 «реликвии».
- **Постоянный процент к Доходу за Испытание** (как было, +10% навсегда) — отклонено. Без потолка это та же петля, что закрывает ADR-0010.
- **Престиж с Финала только во Фронтир** или **«Новая игра+» по кругу** — отклонено. Свободный выбор Поколения использует все восемь Правил.
- **Смена Курса посреди Забега за цену** — отклонено. Решение должно что-то стоить, а цена смены — это лишний расчёт.

## Consequences

- Миграция: `activeChallenge` становится списком, появляется выбранный Курс Забега — один bump `SAVE_VERSION` на оба изменения, если они выходят вместе.
- Выбор Курса, Испытаний и Поколения (с Финала) живёт в подразделе «Престиж» вкладки «Престиж» (её разбивка — #85), до подтверждения Престижа; оверлей ADR-0005 остаётся анимацией.
