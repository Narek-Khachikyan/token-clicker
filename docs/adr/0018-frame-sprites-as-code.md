# Кадровые спрайты как код: Маскоты оживают кадрами

Маскоты и мелкие объекты Сцены рисуются **данными**: палитра и строки сетки в TS, один символ — один пиксель арта, кадр — полная сетка или дифф к базовой. Так уже были устроены Рабочие места и спрайты Событий; теперь так же устроены Маскоты, и у них появляются кадры — дыхание, моргание, работа, радость, пот, тревога. Восемь PNG Маскотов один раз переведены в данные и удалены; пайплайна генерации по-прежнему нет (ADR-0002).

Номер кадра — чистая функция абсолютного времени игры (`state.lastTick`), клипа и фазы, выведенной из хэша id; новых таймеров нет. Компонент подписывается на номер кадра, а не на `state`, поэтому перерисовывается только при смене кадра. Рендер — SVG, один `<path>` на цвет, `shapeRendering="crispEdges"`, масштаб Маскота — только целый (2 CSS px за пиксель арта, ADR-0008). При «меньше анимации» стоит кадр покоя.

**Отменяет пункт Out of Scope спецификации #73** «новые кадры спрайтов Маскотов и перерисовка Маскотов в SVG; анимация Маскотов — только трансформациями» — по прямому решению владельца (#142). Остальное из #73 в силе: без рантайм-зависимостей, без браузерных тестов в репозитории, PNG Сцен не перерисовываются.

## Решения

- **Сцена и оверлей.** Сцена масштабируется как раньше — заполняет колонку (`object-fit: cover`, дробный масштаб). Слой фоновых спрайтов Сцены живёт в пикселях Сцены 384×256 и масштабируется тем же коэффициентом и кропом, что PNG, поэтому стоит пиксель в пиксель на объектах картинки. Целый масштаб Сцены отвергнут: при ширине колонки 360–600 px он дал бы ×1 с пустыми полями.
- **Вспышки.** Не больше трёх вспышек в секунду на всю Сцену (WCAG 2.3.1); мерцание мониторов и ламп — меньше 10 % яркости; красное не мигает. Проверяется тестом над последовательностями кадров.
- **Иерархия реакций.** Тир 1 (покупка, Серия, Достижение) — кадр своего Маскота; тир 2 (Золотой Токен, Глюк, Веха) — кадр и один пульс Сцены; тир 3 (Флагман, смена Поколения, Восстание моделей) — вся Сцена, фон приглушён. Одновременно реагируют не больше двух Маскотов.
- **Вариация без рандома.** Фазы и окна (моргание, холды LED) — от хэша id и номера окна, кадр детерминирован.
- **Палитра по Поколению.** Палитра Маскотов богатеет с Поколением (4 цвета в Поколении 1, полная к Финалу); идентичность Маскота держится силуэтом (ADR-0011). Палитры спрайтов — литералы (ADR-0007).
- **Экспорт.** Canvas допустим только для «Открытки Поколения» (экспорт PNG); для эффектов его по-прежнему нет (ADR-0005).

## Considered Options

- **CSS `steps()` по спрайт-листам PNG** — отвергнуто: нужен пайплайн листов и коммит растров на каждый кадр, кадр нельзя вывести из часов игры, а дифф кадра нечитаем в ревью.
- **Canvas для Сцены** — отвергнуто: ломает текст на подложках (ADR-0002), доступность и единственный путь «меньше анимации» через DOM-атрибуты.
- **Оставить PNG Маскотов и наложить кадры поверх** — отвергнуто: два источника правды о Маскоте, кадры дыхания трогают весь корпус.

## Consequences

- Бюджет арта — ×8 по Лабораториям (ADR-0011): клипы рисуются диффами к базовой сетке, а не целыми кадрами.
- `mascotBob` и CSS `mascot-hop` уходят: Маскот движется кадрами, контактная тень больше не отрывается.
- ADR-0005 в части «маскоты рисуются SVG-rect» снова верен.
